# قوالب الواجهات

الواجهة الحالية تعمل من `8.html` مباشرة حتى تفتح من القرص بدون خادم محلي.

عند تشغيل المشروع عبر خادم محلي يمكن نقل الصفحات إلى هذه القوالب:

- `home.html`: البداية والإعدادات.
- `tournament.html`: مخطط البطولة والمواجهات.
- `board.html`: لوحة الأسئلة.
- `question.html`: السؤال والمؤقت والمساعدات.
- `results.html`: النتائج والسجل.

لا يتم تحميل هذه القوالب حالياً تلقائياً لأن ذلك يتطلب `fetch` وخادماً محلياً، وقد يمنع فتح الملف مباشرة من `file://`.
