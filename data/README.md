# بنك الأسئلة

أضف الأسئلة الجديدة إلى ملف بيانات الفئة المناسب داخل `data/`، ولا تضعها داخل HTML. الفئات الكبيرة لها ملفات مستقلة.

كل سؤال يستخدم هذه الحقول:

- `id`: معرف فريد.
- `category`: اسم الفئة.
- `difficulty`: نوع أو مستوى السؤال.
- `points`: قيمة السؤال، مثل 200 أو 400 أو 600.
- `question`: نص السؤال.
- `answer`: الإجابة الصحيحة.
- `image`: رابط الصورة أو نص فارغ.
- `hint`: التلميح الذي يظهر داخل صفحة السؤال.
- `options`: أربعة احتمالات اختيارية تكشفها مساعدة الفريق، ولا تظهر تلقائياً عند فتح السؤال.

يمنع النظام تكرار نص السؤال بعد إزالة اختلاف المسافات وعلامات الاستفهام.

## أعلام دول العالم

ملف `flags-questions-static.js` هو مصدر أسئلة الأعلام الذي يحمّله التطبيق مباشرة. ملف المصدر النصي موجود في `source/flags-world-countries.txt` للرجوع إليه عند تحديث الأسئلة.

## تحدي الشعارات

ملفا `arab-logos-questions.js` و`logos-questions.js` يحتويان قوائم الشعارات العربية والدولية والخيارات والتلميحات. تُحمّل الشعارات العربية أولاً، ويختار اللوح العربية لأربع قيم من أصل خمس ثم يخصص قيمة 500 للدولية إذا توفرت. أزيلت الشعارات المكررة بين القائمتين وداخل كل قائمة. روابط Google Favicons بصيغة `www` تحتاج اتصالاً بالإنترنت، وتُعرض دون تكبير الأيقونات الصغيرة لتجنب التشويش؛ دقتها الأصلية تختلف حسب الموقع. تظهر رسالة بديلة إذا تعذر تحميل الصورة. الخيارات الأربعة مخفية حتى يستخدم الفريق مساعدة كشف الخيارات.

## تنظيم الملفات

- ملفات `*-questions*.js`: بيانات الأسئلة التي يحمّلها التطبيق.
- `movies-questions.js`, `series-questions.js`, `geography-questions.js`, `sports-questions.js`, `cars-questions.js`: 200 سؤال لكل فئة، مع روابط سجلات Wikidata في حقل `source`، وتلميح وأربعة خيارات لكل سؤال.
- حقل `image` للصورة المرتبطة، وحقل `imageSource` لرابط مصدر الصورة. عند غياب صورة موثقة، ينشئ سكربت الإثراء بطاقة توضيحية خاصة بالموضوع من دون كشف الإجابة؛ ويبيّن `imageKind` الفرق بين صور المصدر والبطاقات التوضيحية.
- أسئلة الأفلام والمسلسلات متنوعة بين سنة الإصدار والنوع وبلد الإنتاج واللغة والطاقم والإخراج/الابتكار. تُفضّل صورة البوستر أو صورة صفحة العمل عند توفرها؛ لا تُجلب الملصقات غير المتاحة قانونياً تلقائياً.
- يمكن إعادة جمع هذه الفئات من Wikidata بتشغيل `node scripts/generate-category-questions.js`، ثم إثراء صورها بـ `node scripts/enrich-category-images.js` مع اتصال إنترنت.
- تشغيل `node scripts/enrich-question-hints-options.js` يحدّث التلميحات والخيارات الأربعة المخصصة للفئات الخمس.
- بعد إعادة توليد أو تغيير بنك فئة، شغّل `node scripts/enrich-question-hints-options.js` لإعادة إنشاء التلميحات والخيارات.
- `source/`: مستندات المصدر والمواد الخام التي لا يحمّلها التطبيق مباشرة.
