# بنك الأسئلة

أضف الأسئلة الجديدة إلى ملف الفئة المناسب داخل `data/`، ولا تضعها داخل HTML. تبقى الفئات الأساسية في `question-bank.js`، بينما القوائم الكبيرة لها ملفات مستقلة.

كل سؤال يستخدم هذه الحقول:

- `id`: معرف فريد.
- `category`: اسم الفئة.
- `difficulty`: نوع أو مستوى السؤال.
- `points`: قيمة السؤال، مثل 200 أو 400 أو 600.
- `question`: نص السؤال.
- `answer`: الإجابة الصحيحة.
- `image`: رابط الصورة أو نص فارغ.
- `hint`: التلميح الذي يظهر داخل صفحة السؤال.

يمنع النظام تكرار نص السؤال بعد إزالة اختلاف المسافات وعلامات الاستفهام.

## أعلام دول العالم

ملف `flags-questions-static.js` هو مصدر أسئلة الأعلام الذي يحمّله التطبيق مباشرة. ملف المصدر النصي موجود في `source/flags-world-countries.txt` للرجوع إليه عند تحديث الأسئلة.

## تنظيم الملفات

- ملفات `*-questions*.js`: بيانات الأسئلة التي يحمّلها التطبيق.
- `games-questions.js` يحتوي 400 سؤال ألعاب، وصوره مرتبطة بصفحات اللعبة أو ببطاقات توضيحية باسمها عند عدم توفر صورة موثقة.
- `proverbs-questions.js` يحتوي 367 سؤال إكمال جديداً؛ مع 33 سؤالاً في `question-bank.js` يصبح مجموع فئة الأمثال 400.
- يمكن إعادة بناء التوسعة بتشغيل `node scripts/expand-games-proverbs.js` مع اتصال إنترنت، ثم إثراء تلميحات وخيارات الفئتين بـ `node scripts/enrich-question-hints-options.js` والصور بـ `node scripts/enrich-category-images.js --category=games`.
- لا يكرر اللوح السؤال داخل الفئة نفسها؛ إذا كان عدد أسئلة فئة قديمة أقل من خمس، يعرض العدد المتاح بدلاً من تكرار البطاقة.
- `source/`: مستندات المصدر والمواد الخام التي لا يحمّلها التطبيق مباشرة.
